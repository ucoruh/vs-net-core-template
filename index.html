CalculatorLibrary — .NET Core Project Template

A complete C# / .NET course-project starter: a class library, a thin console app, xUnit tests, code and documentation coverage generated with both ReportGenerator and the older, ecosystem-native tooling side by side, Doxygen and DocFX API docs, and one-command local and CI/CD release packaging — all driven by a handful of numbered scripts, on Windows and Linux/WSL.

⬇ Download the latest release

(The "Build and Test" badge covers both the build and the unit tests, run on every push on Windows and Ubuntu; "Pages" is this site's own deploy status; the four small badges are code coverage, the fifth is documentation coverage — see Which report is which?. Every badge is regenerated by 7-build-app/10-release/CI, never hand-edited.)

Quick start

:: Windows
4-install-dotnet-sdk.bat
6-install-docfx-and-report-tools.bat
7-build-app.bat
9-open-site.bat

# Linux / WSL
chmod +x *.sh
./4-install-dotnet-sdk.sh
./6-install-docfx-and-report-tools.sh
./7-build-app.sh
./9-open-site.sh

9-open-site serves this site over a small local HTTP server and prints the URL — open it in your browser from there rather than double-clicking site/index.html, so the report pages' <iframe>s are allowed to load (see Showing a report inside your site).
