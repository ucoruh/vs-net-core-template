# Doxygen API docs (ecosystem-neutral)

Renders the same `/// <summary>`, `<param>`, `<returns>` and `<exception>` C# XML doc comments that
DocFX's own [API reference](../api/index.md) reads, but with [Doxygen](https://www.doxygen.nl/) —
the one API-doc tool every template in this course (C, Java, C#) produces the same way. See
[Which report is which?](../guide/reports-explained.en.md) for when to prefer this over the
DocFX-native reference.
