# Documentation coverage — genhtml (native lcov)

Not "how much code is *tested*" but "how much of the public API has an XML doc comment
(`/// <summary>...`)". [coverxygen](https://github.com/psycofdj/coverxygen) turns Doxygen's XML
output into the same lcov format code coverage uses, rendered here by `genhtml`. See
[Which report is which?](../guide/reports-explained.en.md) for why this is intentionally not 100%.
