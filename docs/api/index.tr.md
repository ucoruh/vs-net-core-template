# API dokümanları

API referansı, kütüphanedeki XML doküman yorumlarından (`/// <summary>`) iki araçla, her platform için üretilir:

| Araç | Nedir | Burada nasıl açılır |
|---|---|---|
| **Doxygen** | Ekosistemden bağımsız (C/C++ ve Java şablonlarıyla aynı araç) | bağımsız HTML, çerçevede gösterilir: [Windows](../reports/windows/api-doxygen.md) · [Linux](../reports/linux/api-doxygen.md) |
| **DocFX** | C#'a özgü; kendi menüsü ve araması olan eksiksiz bir site | kendi sitesi, yeni sekmede açılır: [Windows](../reports/windows/api-docfx.md) · [Linux](../reports/linux/api-docfx.md) |

Neden biri çerçevelenip diğeri çerçevelenmiyor: [Sitenizin içinde HTML raporu göstermek](../guide/embed-html-in-site.tr.md).
