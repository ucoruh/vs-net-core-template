# API docs

The API reference is generated from the XML doc comments (`/// <summary>`) in the library, by two tools, for
each platform:

| Tool | What it is | How it opens here |
|---|---|---|
| **Doxygen** | Ecosystem-neutral (the same tool the C/C++ and Java templates use) | standalone HTML, shown in a frame: [Windows](../reports/windows/api-doxygen.md) · [Linux](../reports/linux/api-doxygen.md) |
| **DocFX** | C#-native; a complete site with its own menu and search | own site, opened in a new tab: [Windows](../reports/windows/api-docfx.md) · [Linux](../reports/linux/api-docfx.md) |

Why one is framed and the other is not: [Showing an HTML report inside your site](../guide/embed-html-in-site.en.md).
