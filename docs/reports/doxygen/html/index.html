.NET Core Project Template

A C# / .NET solution template for course term projects: a class library, a thin console app, xUnit tests, code and documentation coverage (generated with both ReportGenerator and the native lcov/genhtml tooling, side by side), Doxygen and DocFX API docs, a DocFX site with every report embedded in its own page, and local + CI/CD release packaging – all driven by a handful of numbered scripts, on Windows and Linux/WSL.

Live site: https://ucoruh.github.io/vs-net-core-template/ – a nicer landing page, a card for every report/guide, and every HTML report shown inside the site. This README is the plain GitHub front page; the polished site's home page source is `docs/home.md`.

Quick start

:: Windows
4-install-dotnet-sdk.bat
6-install-docfx-and-report-tools.bat
7-build-app.bat
9-open-site.bat
# Linux / WSL
chmod +x *.sh
./4-install-dotnet-sdk.sh
./6-install-docfx-and-report-tools.sh
./7-build-app.sh
./9-open-site.sh

9-open-site serves the built site over a small local HTTP server and prints the URL – open that URL rather than double-clicking site/index.html, so the embedded report <iframe>s load (see Showing a report inside your site).

Full instructions, including every prerequisite and its verification command, are in **Install everything** (Turkish: Her şeyi kurma).

The numbered scripts

Each has a Windows .bat and a Linux/WSL .sh version; see Daily workflow for the full table.

# Script Purpose
1 1-pre-commit Git hook: auto-formats staged C# with astyle
2 2-create-git-ignore Regenerates .gitignore's base template
3 3-install-package-manager Chocolatey/Scoop (Windows) or apt refresh (WSL)
4 4-install-dotnet-sdk, 4-install-astyle, 4-install-coverxygen, 4-install-lcov Toolchain installers
5 5-format-code Runs astyle over the C# sources
6 6-install-docfx-and-report-tools Doxygen, Graphviz, and the pinned local dotnet tool set
7 7-build-app Build, test with coverage, Doxygen, every report (both families), zips each report, the DocFX site
8 8-run-app Runs the sample app (never blocks on input)
9 9-open-site Serves the built site over a local HTTP server and opens it
10 10-release Packages binaries + every report + a source archive + the site, publishes a GitHub Release (--dry-run to preview)

CI/CD

  • .github/workflows/ci.yml – builds and tests on Windows and Ubuntu on every push/PR (lean), plus one full site build (Ubuntu) uploaded as a downloadable artifact.
  • .github/workflows/pages.yml – rebuilds the full site and deploys it to the gh-pages branch on every push to main; skipped with an explanation on a private repository unless the PAGES_ON_PRIVATE repository variable is true.
  • .github/workflows/release.yml – the tag-triggered (v*) / manual equivalent of 10-release.

See Releases & private repositories for what works on a private repository with GitHub Free, and the Actions-minutes cost of each workflow.
