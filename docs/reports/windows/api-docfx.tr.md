# API dokümanı - DocFX (C# yerel) — Windows

DocFX'in XML doküman yorumlarından ürettiği, C#'a özgü API referansı. **Kendi başına eksiksiz bir sitedir** (kendi
menüsü, araması ve sayfaları vardır), çünkü DocFX sayfaları kendi site gezinmesiyle üretir. Bu yüzden yeni sekmede
kendi sitesi olarak açılır ve burada çerçevede **gösterilmez**: zaten site gezinmesi olan bir sayfayı çerçevelemek site
içinde site oluşturur.
