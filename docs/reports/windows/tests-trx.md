# Unit test results — Windows

The pass/fail list of every xUnit test with durations, written by the .NET test platform's own HTML logger (the TRX file sits next to it). Open it when a test fails and you want the exact assertion message.

*Built on Windows by `7-build-all-windows.bat`. Windows and Linux/WSL reports are produced separately because they can differ — see [Which report is which?](../../guide/reports-explained.en.md).*
