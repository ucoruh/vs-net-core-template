      99              : ## The numbered scripts
     100              : 
     101              : Each has a Windows `.bat` and a Linux/WSL `.sh` version; see
     102              : [Daily workflow](docs/guide/daily-workflow.en.md) for the full table.
     103              : 
     104              : | # | Script | Purpose |
     105              : |---|--------|---------|
     106              : | 1 | `1-pre-commit` | Git hook: auto-formats staged C# with astyle |
     107              : | 2 | `2-create-git-ignore` | Regenerates `.gitignore`'s base template |
     108              : | 3 | `3-install-package-manager` | Chocolatey/Scoop (Windows) or `apt` refresh (WSL) |
     109              : | 4 | `4-install-dotnet-sdk`, `4-install-astyle`, `4-install-coverxygen`, `4-install-lcov` | Toolchain installers |
     110              : | 5 | `5-format-code` | Runs astyle over the C# sources |
     111              : | 6 | `6-install-docfx-and-report-tools` | Doxygen, Graphviz, and the pinned local `dotnet tool` set |
     112              : | 7 | `7-build-app` | Build, test with coverage, Doxygen, every report (both families), zips each report, the DocFX site |
     113              : | 8 | `8-run-app` | Runs the sample app (never blocks on input) |
     114              : | 9 | `9-open-site` | Serves the built site over a local HTTP server and opens it |
     115              : | 10 | `10-release` | Packages binaries + every report + a source archive + the site, publishes a GitHub Release (`--dry-run` to preview) |
     116              : 
     117              : ## CI/CD
     118              : 
     119              : - `.github/workflows/ci.yml` -- builds and tests on Windows and Ubuntu on every push/PR (lean), plus
     120              :   one full site build (Ubuntu) uploaded as a downloadable artifact.
     121              : - `.github/workflows/pages.yml` -- rebuilds the full site and deploys it to the `gh-pages` branch on
     122              :   every push to `main`; skipped with an explanation on a private repository unless the
     123              :   `PAGES_ON_PRIVATE` repository variable is `true`.
     124              : - `.github/workflows/release.yml` -- the tag-triggered (`v*`) / manual equivalent of `10-release`.
     125              : 
     126              : See [Releases & private repositories](docs/guide/releases-and-private-repos.en.md) for what works on
     127              : a private repository with GitHub Free, and the Actions-minutes cost of each workflow.
