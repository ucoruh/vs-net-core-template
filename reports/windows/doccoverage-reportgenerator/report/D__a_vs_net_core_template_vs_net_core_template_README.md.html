 01# .NET Core Project Template
 2
 3A C# / .NET solution template for course term projects: a class library, a thin console app, xUnit tests, code and
 4documentation coverage generated with **both** ReportGenerator and the native lcov/genhtml tooling side by side,
 5Doxygen and DocFX API docs — **per platform (Windows and Linux/WSL)** — a MkDocs Material site, and local +
 6CI/CD release packaging, all driven by a handful of numbered scripts.
 7
 8**Live site:** <https://ucoruh.github.io/vs-net-core-template/> (MkDocs Material; the DocFX API reference lives under
 9[`/native/`](https://ucoruh.github.io/vs-net-core-template/native/windows/)).

 11## 1. Start your own PRIVATE repository from this template
 12
 131. Click **Use this template → Create a new repository** (green button, top right). **Do not fork**: a fork of a
 14   public repository cannot be made private.

 163. In your new repository: **Settings → Collaborators → Add people** → add the instructor (`ucoruh`) and your team mates

 65## Scripts: same number = same job, platform as suffix
 66
 67| Script | Job |
 68|---|---|
 69| `1-configure-git-hooks-<platform>` | install the pre-commit hook |
 70| `2-create-gitignore-<platform>` | regenerate `.gitignore` (keeps the project section) |
 71| `3-install-package-manager-windows.bat` | Chocolatey + Scoop (Windows only) |
 72| `4-install-tools-<platform>` | .NET SDK, Doxygen, lcov, astyle, dotnet tools, MkDocs Material, coverxygen |
 73| `5-format-code-<platform>` | astyle |
 74| `6-build-and-test-<platform>` | fast: build + unit tests |
 75| `7-build-all-<platform>` | + coverage (both families), doc coverage (both), Doxygen + DocFX, app, site, `release/` |
 76| `8-run-app-<platform>` | run the sample app |
 77| `9-open-site-<platform>` | serve the site on localhost and open it |
 78| `10-release-<platform> [--dry-run]` | publish `release/` as a GitHub Release with `gh` |
 79| `11-clean-<platform>` | delete every generated folder |
 80
 81`<platform>` is `windows` (`.bat`) or `linux` (`.sh`; native Linux and WSL). Helpers live in `scripts/`.
