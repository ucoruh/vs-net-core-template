Detailed Description

Parses and runs the calculator's command-line arguments.

The parsing logic lives here, in the library, instead of in CalculatorApp/Program.cs, so it can be unit tested directly (see CalculatorLibrary.Tests/CalculatorCliTests.cs) without spawning the console application as a process. Program.cs only calls Run(string[]) or RunDemo and prints the result — it never reads from the console, so it never blocks when the app is launched from a script, a build pipeline or CI.

When you rename this sample into your own project, replace this class with your own argument-parsing entry point, keeping the same "parsing is a library function, not something the console shell does inline" shape.

Parses args as <operation> <a> <b> and returns a line of text describing the result.

Parameters
argsExactly three arguments: the operation name (add, subtract, multiply or divide, case-insensitive) followed by the two integer operands.
Returns
A human-readable line such as "2 add 2 = 4".
Exceptions
ArgumentExceptionThrown when the argument count is wrong, an operand is not a valid 32-bit integer, or the operation name is not recognized. The message always ends with UsageText.
DivideByZeroExceptionThrown when dividing by zero.
