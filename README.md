# .NET Core Project Template

A C# / .NET solution template for course term projects: a class library, a thin console app, xUnit
tests, code and documentation coverage (generated with **both** ReportGenerator and the native
lcov/genhtml tooling, side by side), Doxygen and DocFX API docs, a DocFX site, and local + CI/CD
release packaging -- all driven by a handful of numbered scripts, on Windows and Linux/WSL.

## Quick start

```batch
:: Windows
4-install-dotnet-sdk.bat
6-install-docfx-and-report-tools.bat
7-build-app.bat
9-open-site.bat
```

```bash
# Linux / WSL
chmod +x *.sh
./4-install-dotnet-sdk.sh
./6-install-docfx-and-report-tools.sh
./7-build-app.sh
./9-open-site.sh
```

Full instructions, including every prerequisite and its verification command, are in

## Project layout

```
CalculatorLibrary/         Class library (the code you actually test and document)
CalculatorLibrary.Tests/   xUnit tests (normal, boundary and invalid-input cases)
CalculatorApp/             Thin console app -- parsing lives in the library, not here
docs/guide/                This guide, source markdown (EN + TR)
docs/api/index.md           Hand-written landing page for the generated API reference
.config/dotnet-tools.json  Pinned local tools: ReportGenerator, DocFX
Directory.Build.props      Shared MSBuild settings for every project (target net10.0, etc.)
global.json                 Pins the exact .NET SDK version this repo builds with
Doxyfile / docfx.json       Doxygen and DocFX site configuration
```

## The numbered scripts

Each has a Windows `.bat` and a Linux/WSL `.sh` version; see
[Daily workflow](docs/guide/daily-workflow.en.md) for the full table.

| # | Script | Purpose |
|---|--------|---------|
| 1 | `1-pre-commit` | Git hook: auto-formats staged C# with astyle |
| 2 | `2-create-git-ignore` | Regenerates `.gitignore`'s base template |
| 3 | `3-install-package-manager` | Chocolatey/Scoop (Windows) or `apt` refresh (WSL) |
| 4 | `4-install-dotnet-sdk`, `4-install-astyle`, `4-install-coverxygen`, `4-install-lcov` | Toolchain installers |
| 5 | `5-format-code` | Runs astyle over the C# sources |
| 6 | `6-install-docfx-and-report-tools` | Doxygen, Graphviz, and the pinned local `dotnet tool` set |
| 7 | `7-build-app` | Build, test with coverage, Doxygen, every report (both families), the DocFX site |
| 8 | `8-run-app` | Runs the sample app (never blocks on input) |
| 9 | `9-open-site` | Opens the built site |
| 10 | `10-release` | Packages binaries + every report + the site, publishes a GitHub Release (`--dry-run` to preview) |

## CI/CD

`.github/workflows/ci.yml` builds and tests on Windows and Ubuntu on every push/PR -- lean, no
publishing. `.github/workflows/release.yml` is the manual/tag-triggered equivalent of
`10-release`; see [Releases & private repositories](docs/guide/releases-and-private-repos.en.md)
for what works on a private repository with GitHub Free, and the Actions-minutes cost of each.
